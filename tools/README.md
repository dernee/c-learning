# 题库导入工具

把《C语言程序设计题库1000题.docx》转成本网站题库的三个脚本。
**平时用网站不需要碰这个文件夹**，换题库时才用。

## 用法（三步，PowerShell / Git Bash 均可）

```bash
# 1) 解析 docx -> c1000.json（中间格式，先人工抽查）
python tools/parse_bank.py

# 2) 生成 js/questionBank1000.js（写进网站）
python tools/gen_bank_js.py

# 3) 跑回归测试（36 项断言，含与源文档逐一交叉验证）
node tools/test_import.js
```

跑完按 `Ctrl + F5` 刷新 `index.html` 即可看到新题库。

## 三个脚本各管一段

| 脚本 | 职责 | 输出 |
|---|---|---|
| `parse_bank.py` | 解 docx（本质是 zip，读 `word/document.xml`），按正则切题干/选项/答案 | `c1000.json` |
| `gen_bank_js.py` | 把 JSON 转成网站用的 JS 数据文件 + README 头注释 | `js/questionBank1000.js` |
| `test_import.js` | 题库完整性、题型数据、判分逻辑、章节筛选、计分联动、与源文档交叉验证 | 控制台报告 |

## 源文档的三个坑（改脚本前必读）

1. **全角空格 U+3000 是单选题选项的唯一分隔符**
   格式形如 `A语句　B函数　C程序行　D字符`。解析时**绝对不能**把它转成半角空格，
   否则 854 道单选题的 options 会全部塌成一个元素。

2. **选项内容里含大写字母**
   如 `a$b` / `ASCII` / `MAX` / `A65`。**绝不能**用 `([A-D])([^A-D]*)` 全局正则切选项，
   必须「先按全角空格切开，再剥 A/B/C/D 前缀」。

3. **题干可能跨段落**
   形如：
   ```
   21. ［单选 ★］
   转义字符 '
   ' 的作用是
   A输出反斜杠　B换行　C退格　D回车
   ```
   题干不在题号那一行。只用 `^(\d+)\.\s*［(...)\s*(★*)］\s*(.*)$` 抓第 4 组
   会导致 **243 道题题干为空**。必须把选项行之前的正文段落并回题干。

## 答案行的三种格式

```
185. 答案：B　解析：xxx← 单选 / 判断 / 填空
986. 运行结果：10　解析：xxx            ← 程序阅读
997. 参考程序：                        ← 编程题，后跟多行代码块
```

**注意**：源文档存在答案位为空的情况（只有 `解析：`）。解析正则要显式分两支，
否则 `(.+?)` 非贪婪会把「解析：」后面的说明文字当成答案。
目前已知第 185 题源文档漏写答案，脚本内已按 C 语言常识补为 `\n`。

## 数据层不要预转义 HTML

`js/main.js` 在渲染答案时已经调用 `esc()`，所以 `questionBank1000.js` 里的
`answer` / `blanks[].answer` 必须存**原文**。若在生成时预先转义，
`i<5` 会变成 `i&lt;5`，用户输入 `i<5` 永远判错 —— 这是实际踩过的坑。

只有 `stem` / `explain` / `options` 是 HTML 片段，才在生成时转义。

## 已知的源文档特殊情况

- **6 题不含 `main()`**：c792 / c902 / c903 / c935 / c965 / c456，
  源文档本身只给了代码片段（链表反转片段、数组定义等），属正常内容。
- **填空题的 `body` 只有 `（　　）` 答题括号占位符**，`gen_bank_js.py` 已将其丢弃，
  否则页面上会出现重复且无意义的代码框。
